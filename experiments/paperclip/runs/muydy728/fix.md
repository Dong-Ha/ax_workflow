# 검토된 후보 재검증

현재 단계: fix. 기존 후보를 유지했다. 필수 검증 게이트가 미충족이므로 후보 수용, 출시 승인 또는 배포 완료를 주장하지 않는다.

## 계약과 이전 결함

requirements-amendment.md, requirements.md, prototype.md, design.md, test-plan.md, operator-review-AXM-27.md 및 기존 QA JSON 보고를 확인했다. 이전 문서의 대기/다섯 옵션 제안은 보완 명세와 현재 제품 계약으로 정정된다. 상태는 all, inProgress, completed, failed, interrupted, unknown이며 표시 문구는 전체, 진행 중, 턴 완료, 실패, 중단, 상태 미확인이다. unknown을 대기로 추정하지 않는다. 다른 F01–F09/P01–P06 및 선택·삭제·범위 전환 계약은 그대로 유지한다.

system.json, verified-AXM-24.json, verified-AXM-26.json과 topology-verification.json의 기존 실패를 보존했다. 운영자 검토는 수천 카드에서 페이지 전체 accessible-role 로케이터가 초기화 클릭 전에 시간 초과된 것을 독립 진단으로 확인했다. 필터 패널 내부의 정확한 초기화 이름을 사용하는 accessible-role 로케이터로 동일 여섯 사례가 통과했다는 기존 진단과 취소된 실행 기록 역시 보존했다. 이 기존 진단은 이번 실행의 통과 증거로 대체하지 않았다.

## 후보와 변경

현재 experiments/paperclip/verify-agent-topology.mjs는 이미 검토된 SHA-256과 일치한다. 필터 패널 내부 getByRole 버튼과 exact 이름이 적용되어 있다. 11초 제한, chain/star 각각 100·1,000·3,000개 행렬, 카드·맥락·초기화·선택 검사와 결과 스키마를 변경하지 않았다. 이전 fix.md의 제품 배치 비용 원인 추정은 직접 확인된 원인으로 채택하지 않는다.

새로운 제품 결함은 이번 실행에서 확인되지 않았다. src/, server/, 테스트 및 검증기 원본을 수정하지 않았다. 기존 후보의 스타일과 필터·상세 동작을 보존했다. 새 진단 디렉터리의 브라우저 사본은 workspace 루트와 증거 저장 위치만 바꾸어 기존 보고서와 스크린샷의 덮어쓰기를 방지했다. 모든 기대값과 단언은 원본과 동일함을 확인했다.

## 현재 실행 결과

- npm run build: 통과. TypeScript와 배포 번들 생성 완료.
- npm test: 실패. 격리 작업의 네트워크/Paperclip 금지 가드 아래 실행했다. 원시 출력은 저장하지 않았다. 안전 분류만으로 세부 실패 원인을 확정하지 못했으며, 환경 문제로 모든 실패를 단정하지 않는다. 원인 분류를 위해 재시도했지만 필수 통과 게이트를 충족하지 못했다.
- 기존 필터·Claude·OpenCode·Store 단위 회귀: subprocess IPC 없이 원래 단언 그대로 실행하여 통과. 전체 npm test를 대체하지 않는다.
- 독립 필터 비교: 합성 500개 사례 불일치 0. 100·1,000·3,000개 체인의 전체 일치 계산도 통과.
- 브라우저 수용: 샌드박스가 Chromium 시작을 거부했다. 시나리오와 새 스크린샷은 미검증이며 새 진단 보고서의 screenshotSaved는 false다. 사용자 계약의 screenshotSaved:true 수용 조건을 만족하지 못한다.
- 검토된 대형 트리 검증기: 실행을 시도했으나 완료되지 않았고 신규 여섯 사례 보고서도 생성되지 않았다. 브라우저 수용 검사의 시작 거부와 구별하여 기록한다. 여섯 사례 통과로 처리하지 않는다.
- 보존 검사: 제품/서버/테스트 및 이전 단계 산출물의 해시가 동일하다. 검토된 검증기 해시와 브라우저 사본의 단언 동일성도 확인했다.

세부 안전 요약은 fix-validation.json과 workflow-artifacts/fix-reviewed-fdc3622cf3/에 있다. 이전 QA·승인·운영·검토·취소/컨트롤러 보고서는 덮어쓰지 않았다. 의존성 설치, 외부 요청, 실제 기록 접근, Paperclip 실행, 커밋, push 또는 배포를 수행하지 않았다.

전체 npm test와 브라우저 수용/스크린샷 및 여섯 대형 트리 사례가 모두 통과하기 전에는 후보를 수용할 수 없다. 필요한 검증을 이번 격리 환경에서 완료하지 못한 상태를 그대로 개발·QA에 인계한다.
