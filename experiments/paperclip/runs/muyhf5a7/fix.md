# 시스템 QA 실패 재검토

현재 단계: fix. 필수 검증 게이트는 미충족이다. 구현 결함은 확인되지 않았으며 제품 코드나 테스트 기대값을 변경하지 않았다. 출시 승인 및 배포 완료를 주장하지 않는다.

## 입력과 계약 충돌

requirements-amendment.md, requirements.md, prototype.md, design.md, test-plan.md, improvement-request.md, 기존 최상위 QA JSON 보고서와 system.md를 확인했다. system.json 및 verified-AXM-34.json의 최종 verdict는 fail이지만 checks에는 pass가 기록되어 있어 충돌한다. 최종 실패 판정과 실제 이번 실행 결과를 기준으로 하며 이전 기록은 보존했다.

이전 명세의 대기/다섯 상태 및 기본 선택 표현은 현재 제품 계약과 requirements-amendment.md로 정정된 기준을 적용한다. 여섯 상태 키와 정확한 한국어 표시, 새 공급자·세션의 선택 안내, 삭제된 선택의 이용 불가 상태 및 추가 수용된 일치 항목 이동 기능을 축소하지 않는다.

## 결함 원인과 변경 판단

QA는 전체 회귀 테스트 실패를 보고했으나 구현 결함과 환경 제한을 구분하지 못했다. 해당 테스트들은 로컬 HTTP 서버·요청과 합성 Paperclip 실행을 포함한다. 현재 단계는 네트워크 요청, Paperclip 호출 및 workspace 밖 쓰기를 금지한다. 기존 격리 가드를 적용하고 임시 경로를 새 workspace 내부 디렉터리로 지정하여 필수 명령을 실행했다.

같은 원본 테스트를 subprocess 격리 없이 TAP 진단한 결과 136개 중 112개 통과, 24개 실패였다. 실패 진단에서 AX_ISOLATION_BLOCKED가 확인되었으며 로컬 서버·출시 HTTP 검증·Paperclip 연동 시나리오가 실패했다. 이 결과는 현재 제약 아래 전체 회귀를 완료할 수 없음을 보여 주며 제품 구현 결함의 증거로 사용할 수 없다. 서버·어댑터·API·제품 소스·테스트·검증 기대값은 변경하지 않았다. 환경 차단을 우회하거나 테스트를 제외해 통과시키지 않았다.

## 검증 결과

- npm test: 실패, 종료 코드 1. 전체 회귀 통과 게이트 미충족.
- npm run build: 통과, 종료 코드 0.
- 원본 전체 테스트의 subprocess 격리 없는 추가 진단: 112 통과, 24 실패. 전체 npm test 통과를 대체하지 않는다.
- 브라우저 및 독립 이동 검증: 이번 단계에서 실행하지 않았다. 기존 QA의 미검증 상태를 통과로 변경하지 않는다.

fix-validation.json과 신규 fix-system-7c83dee52544/의 안전 요약에 결과를 기록했다. 기존 명세, QA, 승인, 출시, 검증 보고서 및 스크린샷은 보존했다. 네트워크 요청, 실제 Paperclip 실행, 의존성 설치, 커밋, push 및 배포를 수행하지 않았다.

## 재검증 인계

전체 회귀와 브라우저 수용 검증을 허용된 실행 환경에서 QA가 재검증해야 한다. 현 단계에서는 두 필수 명령 모두 통과했다고 보고할 수 없으며 수정 완료 또는 출시 가능 판정을 내리지 않는다.
