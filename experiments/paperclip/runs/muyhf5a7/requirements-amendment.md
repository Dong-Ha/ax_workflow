# 요구사항 검토 보완

주 오케스트레이터의 기존 AX 모델 확인 결과입니다. 원본 공통 상태는 inProgress, completed, failed, interrupted, unknown이며 waiting 상태는 없습니다. 기존 문서의 대기 표현을 중단(interrupted)과 상태 미확인(unknown)의 개별 필터로 정정합니다. 전체 선택을 포함해 여섯 옵션을 제공하며 unknown을 대기로 추정하거나 저장 상태를 변경하지 않습니다. 한국어 상태 표시도 기존 진행 중, 턴 완료, 실패, 중단, 상태 미확인을 유지합니다. 다른 요구사항 F01-F09/P01-P06은 유지합니다. 개발·테스트·출시 승인에서 이 보완을 함께 검토합니다.
