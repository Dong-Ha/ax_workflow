# 시스템 QA 후속 결함 수정

현재 단계: fix. 검색 결과 이동 위치 표시를 구현했다. 필수 검증 게이트는 미충족이며 출시 승인·배포 완료를 주장하지 않는다.

## 입력 및 계약 충돌

requirements-amendment.md, requirements.md, prototype.md, design.md, test-plan.md, improvement-request.md와 기존 QA JSON, 시스템 보고 및 운영 검토를 확인했다. 이전 문서의 대기/다섯 상태 제안은 보완 문서와 현재 계약에 따라 전체, 진행 중, 턴 완료, 실패, 중단, 상태 미확인의 여섯 키로 해석한다. 공급자·세션 전환 후 자동 선택 없이 선택 안내를 표시하는 현재 계약을 유지한다.

현재 system.json은 pass와 빈 findings를 기록하지만 전체 테스트·브라우저·이동 검증의 샌드박스 미검증도 함께 기록한다. 이번 작업의 실패 단계 지정과 이전 통과 기록은 구별하며, 이전 승인·QA·출시·운영 검토 보고를 수정하지 않았다.

## 결함 원인 및 변경

src/App.tsx의 이동 대상은 ref로만 저장되어 이동만으로 렌더링을 갱신하지 않았고, 필터 영역에 요구된 이동 위치 요소가 없었다. 이동 대상 ID를 React 상태로 변경하고 실제 트리 화면 순서의 일치 ID에서 1부터 시작하는 위치를 계산한다. 필터 영역의 요소는 role=status, aria-label=일치 항목 이동 위치, aria-live=polite이며 이동 위치 k / N을 표시한다. N은 맥락 조상을 제외한 실제 일치 개수다.

검색·상태·초기화·공급자·세션 전환에서 이동 대상을 지운다. 이동 전은 0 / N, 결과 없음은 0 / 0이며 다음·이전 및 순환은 화면 순서를 따른다. 같은 세션 갱신에서는 유효한 ID를 유지해 새 화면 순서의 위치를 계산한다. 대상이 삭제되거나 더 이상 일치하지 않으면 이동 상태를 지워 0으로 표시하고, 다시 일치해도 자동 복원·이동하지 않는다.

기존 이동 버튼·단축키·카드 초점·스크롤 처리와 독립적인 선택 상세 흐름을 유지했다. 서버·어댑터·API·원본 기록·테스트 파일·기대값은 변경하지 않았다. 실제 부모 관계, 전체 스냅샷 개수 및 기존 안전 텍스트 경로를 변경하지 않았다.

## 검증 및 제한

- npm run build: 통과. TypeScript 검사와 배포 번들 생성 완료.
- 기존 agent-filter 단위 검증: 24개 전부 통과. 모든 상태 키·표시, 선택 전환·삭제 등의 기존 기대값 유지.
- npm test: 실패. 네트워크·Paperclip 호출 금지와 workspace 내부 임시 쓰기를 적용한 가드 아래 실행했다. 상세 진단을 위한 Node 테스트 subprocess 격리 해제 실행은 144개 중 111개 통과, 33개 실패였고 금지 작업 차단이 확인되었다. 기본 subprocess 실행도 실패했다. 테스트 제외나 기대값 완화로 통과시키지 않았다.
- 오프라인 브라우저 디버그 검증: 샌드박스가 브라우저 시작을 차단해 미검증. 위치 접근성, 순환, 단축키, 초기화, 동일 세션 유지·대상 제거·재등장, 상태 갱신 및 범위 전환 시나리오를 기존 합성 하네스의 별도 사본에 추가했지만 실행 통과나 새 스크린샷을 주장하지 않는다.

안전 요약과 디버그 실행 파일은 workflow-artifacts/fix-current-fcd04745e777/에 새로 작성했다. 브라우저 디버그 결과는 지정된 기존 QA 결과 파일과 별개이며 screenshotSaved=false를 사실대로 기록한다. 기존 QA 결과·스크린샷·명세·승인·배포 계획·출시 산출물은 보존했다. 네트워크 요청, Paperclip 호출, 의존성 설치, 커밋, push 및 배포를 수행하지 않았다.

QA는 허용된 환경에서 전체 회귀 및 브라우저 위치 계약을 재검증해야 한다. 두 필수 명령이 모두 통과하지 않았으므로 단계 완료 또는 출시 가능으로 판정하지 않는다.
