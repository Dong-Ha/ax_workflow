# 선형 필터 결함 수정 및 재검증

현재 단계: fix. 제품 수정과 개발 비교는 통과했으나 전체 검증 게이트는 실패했다. 출시 승인·배포 완료를 주장하지 않는다.

## 계약과 원인

requirements-amendment.md, requirements.md, prototype.md, design.md, test-plan.md, 기존 QA JSON 및 operator-review-AXM-18.md/json을 검토했다. 오래된 문서의 대기·다섯 상태 제안은 보완 명세와 현재 제품 계약의 여섯 상태 및 정확한 한국어 표시로 정정된다. unknown은 상태 미확인이며 대기로 추정하지 않는다. 선택 유지, 공급자·세션 초기화 안내, 선택 삭제 이용 불가 및 전체 스냅샷 집계 계약을 유지한다.

일치 노드마다 조상을 다시 방문하던 계산은 모두 일치하는 연결 목록에서 O(N²)이었다. 기존 수정의 공유 expandedIds는 각 노드의 부모 경로를 한 번만 처리한다. visibleIds에는 일치 노드가 미리 포함되므로 방문 완료 표시로 대신 사용할 수 없다. 이번 수정은 부모 ID를 지역 변수로 읽어 노드당 부모 속성 조회도 한 번으로 줄였다. 조상 계산은 O(N) 시간·O(N) 공간이며 검색 문자열 처리 비용은 기존과 같다.

matched/visible/context 집합과 삽입 순서, 최초 ID 우선 중복 처리, 전체 상태 집계, 순환·자기 부모·누락 부모 처리 및 입력 불변성을 보존했다. 테스트 코드·기대값, UI, 서버 및 어댑터를 수정하지 않았다. 운영 검토의 하네스 격리 수정도 보존했다.

## 현재 검증

- npm run build: 통과.
- npm test: 실패. 총 9개 파일 단위 실행 중 5개 통과, 4개 실패. 격리 환경에서 네트워크·Paperclip 실행 금지 가드를 유지했으며 전체 통과를 주장하지 않는다.
- 기존 필터 단위 테스트: 테스트 프로세스 격리를 해제한 추가 진단 실행에서 동일한 24개 단언 모두 통과.
- 운영 검토 대상 단계 하네스: 추가 진단 실행에서 35개 중 33개 통과, 2개 권한 제한 실패. 테스트 기대값은 변경하지 않았다.
- 공식 고정 시드 500개 그래프 비교: 불일치 0개. 상태 집계 및 순환·중복·누락 부모를 포함한다.
- 추가 500개 그래프, 24,500개 검색·상태 조합: 맵, 순서 있는 집합, 집계 및 입력 불변성 비교 모두 통과.
- 3,000개 연결 목록 중앙값: 기존 431.485ms, 수정 1.403ms. 수정 6,000개 2.49ms, 12,000개 5.294ms. 환경에 따라 달라지는 개발 측정이며 QA를 대신하지 않는다.
- 부모 속성 조회: 3,000 / 6,000 / 12,000개에서 각각 3,000 / 6,000 / 12,000회.
- 기존 오프라인 브라우저 러너: 모든 단언을 유지하고 산출물 위치만 고유 디버그 디렉터리로 바꾼 사본을 실행했다. 샌드박스가 브라우저 시작을 거부했다. 시나리오 및 스크린샷은 미검증이며 실제 결과는 screenshotSaved:false다. screenshotSaved:true 수용 조건을 충족했다고 주장하지 않는다.
- 현재 수정 후 기준 해시 비교: 보호된 기존 문서·보고서·테스트·서버·UI 파일 297개 보존 확인.

현재 실행 증거는 workflow-artifacts/fix-revalidation-io4lzece/에 고유 이름으로 저장했다. 기존 디버그 및 이전 단계 산출물을 덮어쓰지 않았다. 결과는 안전한 요약만 포함하며 원시 출력·API 응답·인증 자료를 저장하지 않았다. 네트워크 요청, 실제 Paperclip 실행, 의존성 설치, 배포, 커밋 및 push를 하지 않았다.

시스템·인수 QA는 권한과 격리 계약을 만족하는 환경에서 전체 npm test와 브라우저·스크린샷을 재검증해야 한다. 현재 필수 통과 게이트는 미충족이다.
