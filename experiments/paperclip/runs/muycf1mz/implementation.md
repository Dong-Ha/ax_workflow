# 구현 결과

현재 단계: implement. 검색·상태 AND 필터, 원본/한국어 역할 표시, 실제 조상 맥락 카드, 고유 전체 스냅샷 집계, 초기화 및 빈 결과/빈 세션 안내를 구현했다. 필터에 숨겨진 선택 상세는 유지한다. 공급자·실제 세션 변경은 검색·상태·선택·이전 스냅샷·활동·페이지 상태를 즉시 정리하며 기본 에이전트를 자동 선택하지 않는다. 선택 삭제는 이전 상세를 제거하고 이용 불가 안내를 표시한다. 이전 범위 및 선택의 지연 응답을 차단한다. 키보드 포커스 표시와 좁은 화면 상세 배치를 보완했다.

## 계약 충돌 처리

requirements-amendment.md는 상태 선택 6개를 요구하지만 현재 명시 요청은 대기 포함 5개다. 최신 요청을 우선해 전체/진행 중/완료/실패/대기를 제공한다. 기존 모델에 waiting이 없어 design.md의 unknown 분류 제안을 UI에서 사용하고, “확정 상태 확인 대기(상태 미확인)”를 명시한다. interrupted는 중단으로 보존하고 전체에서만 일치한다. 실행 대기 상태를 추정하거나 서버 상태를 변경하지 않는다. 이 의미 충돌은 후속 제품/QA 검토 사항이다.

기존 개발 문서의 QA 전용 테스트 책임과 달리 현재 단계 요청은 tests/agent-filter.test.mjs 작성을 명시적으로 허용하므로 단위 테스트를 추가했다. 브라우저 테스트는 이번 단계에서 작성하거나 실행하지 않았다.

## 검증

- 필터 단위 테스트: 통과. 네 검색 필드, 정규화, 다섯 상태의 AND, 전체 집계, 실제 조상/순환/누락 부모, 맥락 선택, 숨긴 선택, 공급자 및 세션 각각의 즉시 상세 초기화와 동일 ID 재사용, 보이는/숨겨진 선택 삭제의 이용 불가 상태, 새 결과의 이전 내용 제거를 검증했다.
- 기존 합성 Codex/Claude/OpenCode 어댑터 회귀: 별도 실행 통과. 임시 자료 경로는 workspace 내부로 제한했다.
- npm run build: 통과.
- npm test: 실패. 기존 tests/paperclip.test.mjs 파일이 실패했고 상세 원인 진단은 제공되지 않았다. 해당 파일은 로컬 HTTP 모의 서버, 네트워크 요청과 Paperclip 실행을 포함하여 격리 지침과 충돌한다. 재실행하거나 기존 테스트를 변경/제외해 전체 통과로 보고하지 않았다. 허용 파일 밖의 수정이 필요한 기존 전체 테스트 실패는 후속 검증 담당자에게 반환한다. 전체 검증 완료 및 출시 승인을 주장하지 않는다.
