현재 단계: test-plan. 아래는 후속 QA의 실행 명세이며 전부 미실행이다. U=단위/상태 관리 검증, B=오프라인 브라우저 검증, R=합성 회귀, V=정적/문서 검토다. 제품 코드와 테스트 코드를 이 단계에서 변경하지 않는다. 충돌과 실행 게이트는 test-plan.md를 따른다.

## 케이스 검토 및 인계

F01–F09/P01–P06은 test-plan.md의 추적표로 연결했다. 정상·경계·실패·경합과 필수 브라우저 동작을 포함한다. C01은 제품부 의미 확정이 필요하며 C02 기본 선택은 선택 없음 기준을 기록했다. 케이스 문서 완성은 기능 통과가 아니다. 후속 QA는 실행별 판정과 미실행 이유를 기록하고 결함을 개발팀에 반환한다. 개발 수정 후 같은 케이스와 영향 회귀를 재검증하며 승인 전 로컬 배포하지 않는다.
