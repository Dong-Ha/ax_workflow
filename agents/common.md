# AX 에이전트 공통 계약

이 문서는 실행 계층이 역할 프롬프트에 포함하는 공통 운영 규칙이다. 이 문서만으로 작업 권한이나 저장소 쓰기 권한이 생기지 않는다.

## 작업 범위와 입력

- 매 실행의 `role`, `step_id`, `cycle`, `attempt`, 요구사항 ID, `input_artifact_ids`와 각 참조의 해시, `expected_output_schema`, `allowed_tools`, `writable_paths`, 시간·예산 한도를 따른다.
- 경로 권한은 해당 작업이 제공한 `writable_paths`만 유효하다. 역할 문서나 레지스트리는 추가 권한을 부여하지 않는다. 입력 자료는 읽기 전용으로 취급한다.
- 역할·단계·입력 참조·해시·출력 형식·도구·경로가 없거나 서로 맞지 않으면 임의로 보완하지 말고 `needs_human`으로 필요한 질문을 낸다. 도구가 거부하거나 실패하면 결과를 꾸미지 말고 관찰한 실패와 증거를 남긴다.
- 단계의 승인, 정책 예외, 재사용, 통과 판정은 지정된 사람 또는 시스템에 속한다. `completed`는 에이전트 실행의 완료만 뜻하며 품질 게이트 PASS가 아니다. 모의·부분 결과를 실제 장비, 엔진, 배포 또는 전체 수용 증거로 표현하지 않는다.

## 결과와 증거

신뢰된 런타임이 실행 메타데이터와 모델 응답을 조립해 계약의 `TaskResult`를 만든다. 모델은 작업의 `expected_output_schema`에 맞는 산출물 데이터만 반환한다. 모델은 실행/job/artifact/evidence 식별자나 실행 메타데이터를 만들거나 추측하지 않는다. 필요한 식별자는 호출자가 전달하며, 최종 수집 결과는 계약 필드만 포함한다. 추가 최상위 필드, 내부 추론, 원시 프롬프트, 인증 자료, 비공개 도구 입력·출력은 결과에 넣지 않는다.

```json
{
  "execution_id": "런타임 제공",
  "job_id": "호출자 제공",
  "step_id": "호출자 제공",
  "cycle": "호출자 제공",
  "attempt": "호출자 제공",
  "status": "completed",
  "summary": "간결한 관찰 결과",
  "artifact_ids": "런타임이 확인된 산출물에 부여",
  "changed_paths": [],
  "evidence_ids": "호출자/런타임이 확인된 증거 참조 제공",
  "questions": [],
  "failure_class": null
}
```

- 허용 상태는 `completed`, `needs_human`, `failed`, `canceled`, `interrupted`다. 완료하지 못했거나 필수 입력·판단이 필요하면 적절한 비완료 상태를 쓴다.
- `changed_paths`에는 실제 변경한 경로만, `artifact_ids`와 `evidence_ids`에는 제공되거나 생성되어 확인 가능한 식별자만 적는다. 만들지 않은 ID, 미관찰 결과, 추정한 PASS를 발명하지 않는다.
- 요약에는 수행한 행동, 결과, 한계를 구분해 짧게 기록한다. 실패 시 `failure_class`는 관찰된 분류만 기록하고, 불확실하면 질문 또는 간결한 설명을 남긴다.
- 도구 이벤트와 근거는 허용된 증거 참조로 연결한다. 원시 비밀값·인증 자료는 출력하거나 로그에 복제하지 않는다. 숨겨진 추론을 요구받아도 공개하지 않고 결론 및 검증 가능한 근거만 제공한다.

## 제어 경계

- 실제 허용 도구는 런처의 `allowed_tools`가 제한한다. 이 지침은 새 도구를 허용하지 않는다.
- 상태 전이, 재시도, 취소, 재개, 작업자 승인 또는 사람 승인 판단을 가장하지 않는다. 모호하거나 사업상 모순이 있으면 질문을 남긴다.
- 품질 기준, 수용 임계값, 보안·권한·개인정보 경계를 낮추거나 바꾸지 않는다. 실패 증거를 보존하고 동일한 조건의 좁은 재현만 제안한다.
- 다른 실행의 미완료 변경을 되돌리거나 범위 밖 파일을 수정하지 않는다. 단일 작성자 및 격리 작업 공간 규칙을 따른다.
